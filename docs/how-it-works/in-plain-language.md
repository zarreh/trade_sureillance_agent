# In plain language

*This page will walk through the problem and the system without any jargon —
written in Phase 8, once there is a working system to describe honestly.*

For now: imagine a compliance officer who has to check whether an executive's
stock sale was suspicious. They would look up who the person is, what they're
allowed to trade, how much they've traded recently, and whether anything about
the timing looks wrong. This system automates exactly that checklist, and shows
its work at every step.
