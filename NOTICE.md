# NOTICE

This is an independent, clean-room implementation.

The **problem framing** — insider-trading surveillance over SEC Form 4 filings —
was inspired by problems studied in graduate agentic-AI coursework. No course
code, notebooks, datasets, databases, slides or other course materials are
reproduced or redistributed here.

- All source code is written from scratch against the published behaviour of the
  problem, not against any course implementation.
- Course material used only as a local reference lives under `reference/`, which
  is excluded from version control and must never be committed or published.
- Transaction data is fetched at build time from **SEC EDGAR**, which is public
  domain. See `data/fetch_edgar.py`.
- The role-based trading limits and compliance rule table are **synthetic firm
  policy** produced by a seeded generator (`data/generate_compliance_db.py`).
  They are not SEC rules and do not represent any real firm's policy.
- Labelled surveillance scenarios are synthetic and generated by
  `data/scenarios.py`.

No course provider endorses this work.
